# 使用说明

本页面向两类人：**只想看图的人**，和**想给自己城市做一张图的人**。

## 1. 三种用法

### 1.1 直接打开成品

- 双击 `dist/beijing.html`（不需要安装任何东西，离线可用）。
- 或在 GitHub Pages 打开 `dist/index.html`（城市索引）→ 选择城市。

### 1.2 本地构建

```bash
python scripts/build.py --city beijing   # 构建单个城市 → dist/beijing.html
python scripts/build.py --all            # 构建全部城市 + dist/index.html（索引页）
```

Windows 双击 `build.cmd` 等价于 `--all`，构建完成后自动打开索引页。

### 1.3 给新的城市做一张图

1. 新建目录 `cities/<城市id>/`，放入 `city.json`（字段定义见 [数据格式](schema.zh-CN.md)）。
2. 可选文件：`build_config.json`（埋深锚点 / 缺省值）、`terrain_grid.csv`（地形高程）、`wiki_line_stations.csv`（逐线车站属性）。缺省时构建会自动降级。
3. 校验数据：`python tests/validate_data.py --city <城市id>`
4. 构建：`python scripts/build.py --city <城市id>` → `dist/<城市id>.html`

## 2. 界面操作

| 操作 | 方式 |
|---|---|
| 旋转 | 鼠标左键拖动 / 单指拖动 |
| 缩放 | 滚轮 / 双指捏合 |
| 平移 | 右键拖动，或 Shift + 拖动 |

| 显示开关 | 地形面 / 站名 / 自动旋转 |
| 线路开关 | 面板「线路」逐线开关；「全显 / 全隐」 |

## 3. 怎么读图

- **数字含义**：站名旁的数字是车站埋深。`34m` 为实测（有公开工程数据），`~31m` 为估算（低置信度）；地面 / 高架站不显示数字，只有小幅视觉偏移。
- **实测口径不一**：卡片里会注明口径（底板 / 轨面 / 站体深度 / 基坑深度 / 报道未注明等）与来源；置信度低的数值请谨慎引用。
- **垂直夸张**：为了让“地下”看得出来，纵向被放大了；同一条线在地下的高低起伏代表真实埋深差异。想要更接近真实比例，可调低「垂直夸张」。
- **远山**：地形面只作参照，个别城市（如北京西山）的高山在渲染中被软压缩，不代表真实高程。
- **颜色**：线路颜色取数据包里各线路的 `colour` 字段，通常沿用官方线网图口径。

## 4. 构建与自检

```bash
python scripts/build.py --all                 # 构建全部城市 + 索引页
python tests/validate_data.py --all           # 数据静态校验（字段 / 引用 / 范围）
npm install && node tests/verify_render.js    # 无头浏览器渲染验证（可选；默认 beijing，可传城市 id）
```

## 5. 常见问题

**Q：为什么没有街道底图？**
A：默认版本刻意不加载任何在线地图瓦片——单文件、离线可用，也避免底图合规问题。需要底图时可以接入合规服务（腾讯 / 高德 / 百度 / 天地图），属于路线图功能。

**Q：我只有站名和线路，没有埋深，能做吗？**
A：能。`city.json` 只需要站名、坐标、线路与站序；没有埋深的城市，地下站会按线路缺省值（默认 20 m）显示为“估算”。想要更准，补充 `build_config.json` 的锚点即可。

**Q：想加一个城市但不想写代码？**
A：把 `cities/<城市>/city.json` 准备成 [数据格式](schema.zh-CN.md) 的样子即可，构建脚本会自动处理；字段含义和示例都在文档里。

**Q：坐标系有什么要求？**
A：一律 WGS-84。若要与国内地图服务的底图叠加，需要先转成 GCJ-02，并遵守相应服务条款。
