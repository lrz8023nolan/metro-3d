## 置信度框架

查看器给每个地下站台层标注三种来源之一：

| 类型 | 含义 | 界面 |
|---|---|---|
| `truth` | 上表一类的公开工程数据 | 直接显示 `34m`，卡片含口径与来源 |
| `est` | 推算：锚点 + 线路缺省值沿线插值 | 显示 `~31m`，卡片写明"估算（低置信度）" |
| `above` | 高架/地面站，无需埋深；+8.0 / +1.2 / +0.4 m 仅为视觉堆叠 | 不显示数字 |

即使在 `truth` 内，口径也不完全统一（底板 / 站体结构 / 基坑 / 未注明的"埋深"），
个别数字来自单一报道——`depth_conf` 如实记录了这一点，`low` 的建议谨慎使用。

## 已知注意点

- **覆盖率**：37/424 座车站有公开埋深（约 9%），其余全部为插值结果。
  补充带来源的埋深是当前最主要的数据缺口。
- **锚点是估算**：`build_config.json → depth_anchors` 是作者按线路年代与
  深度规律做的近似，**不是**有出处的数值。
- **范围**：排除 6 座未开通车站（福寿岭、53 号、陶然桥、高家园〔14 号线〕、
  广渠门外、老观里）；在建线路（22、28 号线、13 号线拆分、1 号线支线、
  M101、京雄 R1 等）未纳入。
- **状态**：八角游乐园封站改造中（通过不停车）；苹果园 / 古城 / 八宝山
  2026-05-16 恢复运营，苹果园为三线换乘。
- **吸附**：OSM 换乘枢纽的站点节点可能离轨道最远约 240 m（出入口 vs 站台），
  构建时统一吸附到折线上——位置以线网为准，而非出入口实际位置。
- **显示**：金安桥以西的山体（最高 781 m）在渲染时做了软压缩（仅显示处理，
  数据未动）。
- **版本**：线网为 2026-10 状态，之后的开通与调整未反映。
